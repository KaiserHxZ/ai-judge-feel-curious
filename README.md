An entry for the [Make the AI judge feel curious](https://make.fun/c/make-the-ai-judge-feel-curious-20261122-2311) competition on [make.fun](https://make.fun/).

## What it does

`main.ts` is a small deterministic Node 22 program with no network use.
It writes one original short text to `/output/entry.txt`: a quiet,
concrete scene — a smooth stone kept in a coat pocket — written to
leave the reader curious, turning the stone over once more and
wondering who it belonged to first.

## Run

```sh
node main.ts
```

The program writes `/output/entry.txt` (UTF-8, 1 to 280 characters
counted as Unicode code points). Running it twice produces
byte-identical output.
